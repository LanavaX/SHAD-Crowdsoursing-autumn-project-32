# Промпты моделей: v1 (дым) и v2 (обновлённые)

## v1 — использовались в дымовом прогоне 2026-11-08

| Модель | Промпт |
|---|---|
| grounding_dino_tiny | `butterfly.` |
| llmdet_large | `butterfly.` |
| mm_grounding_dino_large | `butterfly.` |
| owlv2_base | `a photo of a butterfly` |
| omdet_turbo | `butterfly` |
| qwen3_vl_2b / 4b | `Detect every adult butterfly visible in the image (no moths, no caterpillars). Reply ONLY with a JSON array, one object per butterfly: [{"bbox_2d": [x1, y1, x2, y2]}] where coordinates are integers in 0-1000. If there are no butterflies, reply [].` |

## Наблюдения по v1 (дым, 100 фото; рамки после рабочих порогов)

- **Мотыльки (15 фото)**: llmdet_large и mm_grounding_dino_large отметили 15/15, omdet_turbo 12/15, grounding_dino_tiny ~12/15, qwen3_vl_2b 4/15, owlv2_base 5/15, **qwen3_vl_4b 0/15** (лучший).
- **Растения (15 фото)**: owlv2_base и оба qwen — 0 FP; grounding_dino_tiny рисует ~1 рамку почти на каждом растении (13/15); остальные редкие FP.
- **Псевдо-GT контаминирован**: рамки консенсуса есть на 11/15 мотыльков и 10/15 растений — на низком пороге 0.05 четыре модели регулярно «голосуют» за мотылька/цветок, кворум проходит. Пример: 761155806 (цветок) — рамка gt появилась из слабых (низкоскоовых) совпадений, после порога выжила только рамка gd_tiny. Вывод: дымовые F1 — только отладка; чистота на двойниках оценивалась глазами/таблицей, а не F1.

## v2 — новые подробные промпты (базовые; контрастивный вариант остаётся экспериментом A)

Идея: детекторам с фразовым запросом длинные инструкции противопоказаны (обучены на коротких
фразах — разваливаются на прозе), поэтому «подробность» для них = перечисление вариантов
появления бабочки; VLM (qwen) получает полноценную инструкцию с описанием сложных случаев
и отрицаниями.

| Модель | Промпт v2 |
|---|---|
| grounding_dino_tiny / mm_grounding_dino_large / llmdet_large | `adult butterfly. small butterfly. distant butterfly. camouflaged butterfly.` |
| owlv2_base (3 запроса-класса) | `a photo of an adult butterfly` + `a photo of a small distant butterfly` + `a photo of a camouflaged butterfly` |
| omdet_turbo | `adult butterfly` |
| qwen3_vl_2b / 4b | см. `QWEN_PROMPT` в `code/lib/models.py` — полная инструкция: мелкий/дальний/замаскированный/перекрытый/обрезанный объект, отдельная рамка на каждую бабочку, отрицания (мотыльки: крылья домиком + перистые усики, гусеницы, куколки, другие насекомые, цветы), только JSON `bbox_2d` 0–1000 |

Контрастивный промпт для эксперимента A (не базовый): `adult butterfly. moth. caterpillar. pupa.`
с фильтром рамок по метке «butterfly» — гипотеза о снижении FP на двойниках.

## Итог сравнения v1 vs v2 на дыме (2026-11-08, пороги — разведанные по каждой версии)

Лишние рамки на мотыльках/растениях (15+15 фото), рамок на фото бабочек (70 фото, эталон ~83):

| модель | мотыльки v1→v2 | растения v1→v2 | бабочки v1→v2 |
|---|---|---|---|
| grounding_dino_tiny | 17→17 | **19→6** | 88→95 |
| owlv2_base | 5→9 | 0→0 | 71→76 |
| qwen3_vl_2b | 4→7 | 0→0 | 79→80 |
| qwen3_vl_4b | 0→5 | 0→0 | 72→80 |
| llmdet_large | 16→16 | 1→1 | 68→73 |
| mm_grounding_dino_large | 15→33 | 5→1 | 68→153 (дубли) |
| omdet_turbo | 12→13 | 4→6 | 71→80 |

**Вывод: подробные промпты систематического выигрыша не дали** — мотыльков столько же или больше
почти везде; единственный явный плюс — gd_tiny на растениях. Это честный результат «изменение
не улучшило — тоже результат» (прямая опора для защиты).

**Решение по базовым промптам**: gd_tiny — v2-мультифраза; остальные — v1 (как в `lib/models.py`).
Подробный Qwen-промпт сохранён как `QWEN_PROMPT_DETAILED` → эксперимент D на golden set
(у 4B на дыме полнота выросла 72→80, но +5 FP на мотыльках — пусть решает настоящая разметка).

Артефакты: прогоны `runs/smoke/` (v1) и `runs/smoke_v2/` (v2), листы `sheets/` в обоих.
